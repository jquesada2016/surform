The languageFulltext indexes

Fulltext indexes

Analyzers define how fulltext search reads text: how to split it into terms, and how to normalize each term. They are named definitions a fulltext index points at.

The shape

Three optional clauses — an analyzer with none is legal but inert:

  • tokenizers: — how text splits. blank (whitespace), camel (camelCase boundaries), class (alphanumeric runs), punct (punctuation).
  • filters: — term transformations, order matters: ascii, lowercase, uppercase, snowball(<language>) (stemming — 18 languages, bare keywords, short aliases like en accepted), edgengram(min, max) (prefix matching for autocomplete), ngram(min, max) (fuzzy matching).
  • function: — a preprocessing function of your own (it must accept and return a string), running before tokenization.
