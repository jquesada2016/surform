The languageEvents

Events

An event is a trigger: when a record in its table changes, its SurrealQL runs. when: filters which changes fire; then: is the action (or a comma list of actions).

The shape

on: names the table (standalone form — nested inside the table block, the line disappears). The body sees SurrealDB's event variables:

variablevalue
$event'CREATE', 'UPDATE', or 'DELETE'
$beforethe record before the change (nothing on create)
$afterthe record after the change (nothing on delete)
$valuethe record itself — pre-change on delete, post otherwise
