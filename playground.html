This page runs the Surform compiler in your browser, compiled to WebAssembly (3.3.0 grammar) — the same parser and codegen the surform CLI runs. Edit the schema; the diagnostics, the DDL, and the canonical form update as you type. Nothing you type leaves this tab.

surform build — the DDL the engine would run

surform fmt — the same schema, canonical form
sdl

On a clean parse the emission is re-checked through the official SurrealQL parser; if the diagnostics card shows SDL-E1060, the compiler emitted DDL the parser rejects — a Surform bug (see how this site is verified). The editor's SDL highlighting uses the compiler's keyword table; SurrealQL itself — the DDL pane, and the expressions, function bodies, and views embedded in the SDL — is inked by SurrealDB's official SurrealQL grammar (the same one their editors ship).

Surform is an independent open-source tool for SurrealDB — not affiliated with SurrealDB Ltd. Built from commit c2c4ae4 · examples ran against SurrealDB 3.3.0 when the site was built.
